## Описание компонента

Компонент Localizator дает возможность создания языковых версий / сателитов без контекстов, с автоматическим
переводом всех полей ресурса, включая дополнительные параметры, а также автоперевод лексиконов.

Для работы должны быть включены ЧПУ (friendly URLs)
Компонент требует установки pdoTools и MIGX.

## Настройка

Создание псевдоконтекстов «локализации» (можно вместе работать через site.ru/en/ и ch.site.ru)
![псевдоконтексты](https://file.modx.pro/files/a/2/d/a2d8c479da8603723ac5b480e0e2408d.png)

У ресурса есть таб, где заполняются все стандартные поля ресурса + сео + дополнительные поля, далее по нажатию кнопки это все можно перевести на другие языки.
![таб локализатора](https://file.modx.pro/files/1/5/2/152cc01c77ac4a8a5c923cb7204f678f.png)
![окно локализации](https://file.modx.pro/files/3/b/3/3b382b1f2be63655d70f844555369527.png)



Для работе со сниппетами пакета pdoTools (pdoResources, pdoMenu) для выборки ресурсов, необходимо
заменить значение системной настройки:

```
pdoFetch.class = pdotools.pdofetchlocalizator
```

Название					| По умолчанию									| Описание
----------------------------|-----------------------------------------------|------------------------------------------------------------------------------------------
**localizator_default_language**				| Нет								| Ключ локализации по умолчанию
**localizator_check_permissions**				| Нет								| Проверять права на редактирование локализаций ресурса
**localizator_disabled_templates**				| —								| ID шаблонов через запятую; для ресурсов с этими шаблонами вкладка «Локализатор» не показывается
**localizator_default_translator**					| Yandex											| Переводчик для автоматического перевода: Yandex, Google, DeepL или пусто для копирования без перевода
**localizator_key_yandex**					| Нет											| API ключ для Яндекс переводчика, https://translate.yandex.ru/developers/keys
**localizator_key_google**					| Нет											| API ключ для Google Translate
**localizator_key_deepl**					| Нет											| API ключ для DeepL
**localizator_translate_fields**					| pagetitle,longtitle,...											| Список полей для перевода при автоматическом переводе, в том числе доп.поля
**localizator_translate_translated**					| Нет											| При автоматическом переводе переводить ПУСТЫЕ поля у существующих локализаций
**localizator_translate_translated_fields**					| Нет											| При автоматическом переводе перезаписывать все поля локализации


Дополнительные поля (TV) доступны в локализации, если в настройках TV включён чекбокс «Доступен в локализациях».

Для правильной работы с mFilter2 сделан обработчик. Нужно указать **mse2LocalizatorFilter** в системной настройке **mse2_filters_handler_class**

## Настройка локализаций типа site.ru/en/
Для правильной работы нужно указать правило в **.htaccess**
```
RewriteRule ^(ru|en)/assets(.*)$ assets$2 [L,QSA]
```
Либо в конфигурации **nginx**
```
location ~ ^/(ru|en) {

    rewrite ^/(ru|en)/(favicon.ico|assets.*)$ /$2 redirect;

    try_files $uri $uri/ @rewrite;
}
```

## Возможности и изменения (1.0.9, 1.1.0)

**Переводчики и копирование (1.0.9)**  
Доступны переводчики Yandex, Google и DeepL. В настройке «Переводчик для автоматического перевода» можно указать Yandex, Google, DeepL или оставить пусто — тогда при автоматическом переводе строки просто копируются без вызова API.

**Отключение вкладки по шаблонам (1.1.0)**  
В настройке **localizator_disabled_templates** задаётся список ID шаблонов через запятую. У ресурсов с такими шаблонами вкладка «Локализатор» в форме документа не отображается.

**Ресурсы-ссылки и симлинки (1.1.0)**  
Для ресурсов типа «Ссылка» (modWebLink) и «Симлинк» (modSymLink) в форме локализации снова отображается поле «Ссылка» (content). Можно задавать разный целевой ресурс для каждого языка. При сохранении документа обновляется только язык по умолчанию, значения остальных языков не затираются.

**Вывод TV в Fenom (1.1.0)**  
При выводе TV (например, картинки) через `$_modx->resource.img` путь к файлу формируется корректно, без дублирования basePath (раньше могло получаться вида `assets/images/assets/images/...`).

**Прочие исправления (1.1.0)**  
При редактировании заголовка из грида локализаций в БД записывается корректный ключ языка (из скобок, например `en`), а не название. Убран вывод в консоль браузера при открытии окна редактирования.
